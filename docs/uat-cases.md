# 浪乘 驗收案例（UAT）

來源：Issue #1（MVP 規格，PR-AUTH／TRIP／FIND／REQ／CONTACT／NOTIFY／CANCEL／METRIC）、Issue #8（PR-TRIP-05、PR-MEET、PR-SHARE），以及使用者故事「司機阿凱」「乘客小魚」（2026-11-13 對話整理）。

**編號規則**：`TC-<AREA>-NN` 一經發出即凍結；退役的案例保留段落、狀態改為 `retired`，編號永不重發。證據目錄 `docs/uat/` 以編號命名。

## 測試環境與帳號

- **環境 L（本機）**：`.env` 設 `DEV_LOGIN=1`，`npm start` 後以 `http://localhost:3001` 開啟；每個角色用一個獨立的無痕視窗，在「開發用假登入」輸入名字登入。
- **環境 R（真 LINE）**：ngrok 的 HTTPS 網址，`.env` 的 `BASE_URL` 指向它、`DEV_LOGIN` 註解掉，LINE Login callback URL 已更新；各角色用不同 LINE 帳號（需在 LINE Developers 的 Roles 加為測試者）。
- **角色**：司機「阿凱」；乘客「小魚」「小浪」「小沙」；訪客＝未登入的瀏覽器。
- **標準行程**（前置條件提到時照填）：日期明天、出發 05:00、浪點北堤、上車點「後山埤站、板橋新埔站」、座位 2、載板「僅短板」、單程 150。

## TC-AUTH-01 — 用 LINE 登入並加官方帳號好友
- **狀態**：active
- **負責人**：Ching-Ya Chang
- **來源**：PR-AUTH-01／乘客小魚
- **角色**：乘客
- **前置條件**：環境 R；小魚的 LINE 帳號從未登入過浪乘
- **步驟**：
  1. 開啟首頁，點下方「登入」分頁
  2. 點「使用 LINE 登入」
  3. 在 LINE 授權頁按同意，出現加官方帳號好友的畫面時加入好友
- **期望結果**：回到浪乘，下方分頁從「登入」變成「我的」；LINE 好友清單出現浪乘官方帳號
- **最近判定**：未判
