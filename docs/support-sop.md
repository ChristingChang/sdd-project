## 一、刪除帳號

### 1. 確認是本人

**請對方從 LINE 官方帳號（Surfpool，`@777txkeq`）私訊**一句話，例如「我要刪除浪乘帳號」。**不要**收身分證件或任何證件照片（過度蒐集）。

在 LINE Official Account Manager 的聊天室看到私訊後，比對：

- 私訊者的 LINE 顯示名稱，和下一步 `--find` 查到的名稱一致
- 信裡寫的聯絡方式（LINE ID 或手機），和查到的聯絡方式一致

對不上就回信請對方確認，不要刪。

### 2. 查使用者編號

```bash
npm run delete-user -- --find <LINE 顯示名稱或聯絡方式>
```

會列出 `#編號「名稱」 聯絡方式：…`，最多 20 筆；已刪除的帳號不會列出。

### 3. 刪除

```bash
npm run delete-user -- <使用者編號>
```

指令會先印出預覽，**沒有輸入 `yes` 不會改任何資料**：

- 使用者編號、名稱、聯絡方式
- 他當司機、還沒出發的行程（每趟的已接受、待確認人數）：全部會取消
- 他當乘客、還沒出發的申請：全部會退出，已接受的會釋出座位
- 刪除後會收到推播的人

確認無誤後輸入 `yes`。執行內容（PR-ACCOUNT-01～03）：

- 聯絡方式、頭像清空；名稱改為「已刪除的使用者」；所有登入立即失效
- 這筆資料不再對應原本的 LINE 帳號；對方之後再登入會是全新的帳號
- 還沒出發的行程取消、申請退出，相關的人收到和平常一樣的推播
- 已出發的行程保留（成行統計不變），但清除上車點、精確集合點與備註

最後一行若有「推播失敗」，代表有人沒收到通知（多半是沒加官方帳號好友）。請看預覽裡的名單，必要時另外聯絡司機或乘客。

### 4. 回覆

回信告知已刪除、刪除日期，以及「已出發的行程紀錄已去識別化保留，僅用於統計」。

## 二、查詢、閱覽、製給複本

同樣先請對方從官方帳號私訊確認是本人。目前**沒有匯出指令**，可以：

1. 用 `--find` 查到編號與聯絡方式
2. 請對方登入後打開「我的」頁，那裡列出他發的行程與申請；需要書面複本時，經營者整理成文字或表格用 email 寄出

15 天內回覆。

## 三、騷擾、放鳥檢舉

1. 回信請檢舉人提供：對方名稱、哪一趟行程（日期時間或網址）、發生什麼事、截圖（有的話）
2. 必要時透過官方帳號私訊被檢舉人了解狀況
3. 依使用須知處理：
   - **輕微、初犯**：私訊提醒
   - **明顯違反使用須知、累犯、騷擾**：停用帳號。**目前沒有單獨的「停用」或「下架單一行程」功能**，用刪除帳號指令代替（會取消他所有還沒出發的行程並登出），並在回信說明
4. 回覆檢舉人處理結果（不透露被檢舉人的個資）

## 四、資料外洩

發現疑似外洩（例如主機被入侵、資料庫檔案外流）：

1. 先止血：`fly secrets` 換掉 LINE 的 channel secret 與 access token；必要時暫停網站（`fly scale count 0`）
2. 查清楚影響範圍：哪些資料、哪些人、什麼時間
3. **通知當事人**，以 LINE 推播或 email，內容包含：
   - **事實經過**：什麼時候、發生什麼事、外洩了哪些資料（例如聯絡方式、LINE 顯示名稱）
   - **已採取的措施**：已更換憑證、已修補、已暫停服務等
   - **諮詢管道**：客服信箱，以及當事人可以自己做的事（例如留意可疑來電或訊息）
4. 留下紀錄：時間軸、通知了誰、用什麼方式

## 五、在正式環境（Fly.io）執行指令

資料庫在 Fly 的 volume 上（`/data/carpool.db`），指令要在主機上跑。機器閒置時會自動關機，先打開網站把它叫醒。

```bash
fly ssh console
```

進到機器後：

```bash
cd /app
node --disable-warning=ExperimentalWarning src/delete-user.js --find 小魚
node --disable-warning=ExperimentalWarning src/delete-user.js 12
exit
```

- 刪除時要在這個互動畫面裡輸入 `yes`，所以用 `fly ssh console` 進去再執行，不要用 `-C` 一次帶指令
- 如果輸出出現「[推播未設定]」，代表這個 ssh 環境讀不到 `LINE_MESSAGING_ACCESS_TOKEN`，推播沒有送出，請改用其他方式通知預覽名單上的人
- 刪除前建議先照 `docs/deploy-fly.md` 的備份步驟留一份資料庫副本
