# 浪乘 使用者故事：司機阿凱、乘客小魚

整理日期：2026-11-13；2026-11-19 更新（聯絡方式格式檢查，PR-CONTACT-03）。內容已逐條對照當時的程式碼（`src/service.js`、`src/app.js`、`src/share.js`、`public/app.js`）。
用途：之後做宣傳文案、向別人說明產品、以及驗收（UAT 案例在 `docs/uat-cases.md`，已經用這兩個故事拆好；電腦能跑的部分用 `npm run uat` 自動執行，截圖與報告在 `docs/uat/`）。

> 宣傳前提：正式網址必須是 HTTPS。「分享行程」和「複製發文」在非 HTTPS 的網址會退回成只複製連結，或要手動長按複製。

## 🚗 司機的故事：阿凱

**週五晚上：決定出發**
阿凱看了浪況，決定週日早上去北堤，車上還有 3 個空位。

**第一次使用（只有這一次比較麻煩）**
1. 打開浪乘，按「LINE 登入」。
2. LINE 會邀請加浪乘官方帳號好友，這一步一定要加，不然之後收不到任何通知。
3. 填聯絡方式：LINE ID（例如 `akai_surf`）或手機號碼（例如 `0912-345-678`）。打「私訊我」這類文字會被擋下，提示要填 LINE ID 或手機號碼。只有被接受的乘客看得到。

**發行程**
4. 第一次要填完整：日期、出發時間、浪點、上車點、座位、載板條件、車資。也可以填精確集合點（選填），例如「南港車站 2 號出口，白色 RAV4」。
5. 第二次以後只要選日期，其他欄位都會自動帶入上一趟的資料，按「發布」就完成。

**讓人看到**
6. 在行程頁按「分享行程」，手機會跳出分享選單，選 LINE 群就會帶出整篇發文文字和連結。
7. 按「複製發文（FB／Threads）」，貼到 FB 社團和 Threads。格式已經排好，字數也在 Threads 500 字限制內。發文裡不會出現聯絡方式和精確集合點。

**有人申請**
8. 手機收到 LINE 推播：「小魚 申請了你 2026-11-16 05:00 的行程」，下面附行程連結。
9. 點進去，看到申請人的名字、要在哪裡上車、帶什麼板，按「接受」。
10. 剩餘座位自動減一。坐滿之後頁面標示「已滿」，系統會擋下新的申請，不用回任何人「還有位嗎？」
11. 接受之後，可以看到小魚的聯絡方式。如果阿凱有填集合點，小魚收到的接受通知裡會直接附上。

**計畫有變**
- 阿凱臨時不去了：按「取消行程」，所有待確認和已接受的申請人都會收到推播。
- 已接受的乘客退出：阿凱會收到推播，座位自動釋放，別人可以再申請。

**週日清晨**
12. 到集合點接人。萬一找不到人，就用對方的聯絡方式聯絡。

**下週**
13. 再發一趟，只要選日期。

> **阿凱少做的事：回私訊、確認座位、說明在哪上車、每次重打一篇貼文。**

## 🏄 乘客的故事：小魚

**週五晚上：找車**
1. 在 FB 社團、Threads 或 LINE 群看到阿凱的貼文，點了連結。也可以直接打開浪乘首頁，預設顯示明天的所有車，還可以依浪點篩選。
2. 每趟車都看得到剩幾個座位、能不能載板、車資多少。坐滿的會標示「已滿」。

**看細節**
3. 點進行程頁，看上車點、回程時間、備註。不用登入就能看。

**申請**
4. 按「使用 LINE 登入後申請」（第一次也要加官方帳號好友），登入後會回到原本那趟行程。
5. 第一次要填聯絡方式，一樣只收 LINE ID 或手機號碼，確保被接受後司機真的聯絡得到人。
6. 選上車點和板型。司機的車不載長板的話，選單裡根本不會出現長板，不會申請了才被拒絕。

**等待**
7. 狀態顯示「待確認」，可以在「我的」頁面看到所有申請。
8. 收到 LINE 推播：「已被接受，可以查看司機聯絡方式」，司機有填集合點的話，推播裡會一起附上。打開行程頁就看得到司機的聯絡方式。
   - 如果被拒絕，也會收到推播，回首頁找別班車。

**計畫有變**
9. 臨時不去了，按「退出行程」。如果已經被接受，司機會收到通知，座位也會釋放給別人。

**週日清晨**
10. 照著集合點（推播或行程頁上都有）去等車，出發。

> **小魚少做的事：一篇篇滑貼文、私訊等司機回覆、不確定還有沒有位、問在哪上車。**

## 還沒處理好的地方

1. **沒加官方帳號好友，整個故事就斷了。** 阿凱收不到申請、小魚收不到接受通知，系統也不會提醒任何人。這是上線後最大的風險。（建議優先處理）
2. **司機一直沒回應怎麼辦？** 小魚申請後，如果阿凱都沒按接受或拒絕，小魚只能一直等，沒有逾時或提醒。發文到出發的中位數只有 18.7 小時，等不起。
3. **坐滿之後，其他待確認的人不會被通知。** 坐滿時，還在「待確認」的申請不會自動拒絕，也不會收到推播，只會在行程頁看到「已滿」。這和第 2 點是同一類問題。
4. **待確認的乘客退出，司機不會收到通知。** 這符合規格，但阿凱可能會疑惑：「剛剛那個申請怎麼不見了？」
5. **沒填集合點，小魚就只有上車點。** 集合點是選填，沒填的話推播裡不會有，雙方要自己用聯絡方式約。
6. **手機號碼只收台灣 09 開頭。** 外國朋友或用 `+886` 格式的人會被擋，只能改填 LINE ID。格式對了也不代表號碼或 ID 真的存在，系統不會驗證。

處理方式：用 `/grill-with-docs` 想清楚再開票。

## 宣傳素材（可直接用）

**給司機**
> 發一次行程，下週只要選日期。不用回私訊、不用確認座位、不用每次重打一篇貼文。

**給乘客**
> 不用一篇篇滑貼文。剩幾個位、能不能帶板、車資多少一眼看到，被接受就收到 LINE 通知。

**可以強調的賣點（都已經做好）**
- 首頁預設看明天的車，可以依浪點篩選
- 坐滿自動擋下申請，不會超賣
- 不載長板的車，乘客根本選不到長板
- 聯絡方式只給被接受的人看，公開頁面和發文都不會出現
- 聯絡方式一定是 LINE ID 或手機號碼，被接受後聯絡得到人
- 一鍵產生 FB／Threads 發文，字數已控制在 Threads 限制內

**宣傳時不要說的話（目前做不到）**
- 「司機一定會回覆」：沒有逾時或提醒
- 「一定收得到通知」：沒加官方帳號好友就收不到
